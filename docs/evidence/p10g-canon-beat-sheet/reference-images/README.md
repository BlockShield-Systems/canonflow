# Character Reference Sheets

Canonical visual references for the two lead characters of
*Y.D. - When Paradise Glitches*.

| File | Character |
|---|---|
| `r4/demian-character-reference.jpg` | Demian |
| `r4/yd-character-reference.jpg` | Y.D. |

Each sheet contains four views of the same character in a single image,
ordered left to right: front view, back view, left side view, right side view.
This layout is used to keep shot-level generation consistent across the
production pipeline.

Both sheets were generated with Google Gemini Pro.

These images depict real, identifiable persons and are published solely as
